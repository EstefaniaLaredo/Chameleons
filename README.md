# Chameleons

Practica de **Implementacion de Machine Learning en Unity** - Game Development, Universidad del Valle.
Docente: Erick Salomon Cespedes Gamarra.

## El juego

Celulas aparecen en pantalla durante rondas de 10 segundos y el jugador debe eliminarlas
haciendo clic sobre ellas. Ronda tras ronda las celulas aprenden que colores y que tamanos
las ayudan a no ser vistas, y terminan camuflandose con el fondo.
